1. 사이트 분석 요약 (현황)

서비스 구성

  • 주요 메뉴 (4영역): 통계정보, 통계자료, 참여·공유, 소개·알림
  • 통계정보: 제공현황통계, 최신·인기통계, 국제통계, 통계공표일정
  • 통계자료: 통계연보, 통계메타DB, 통계용어, 통계법령자료
  • 참여·공유: 통계오류신고, 개발커뮤니티, OPEN API 신청, 마이크로데이터 신청
  • 소개·알림: 통계누리 소개, 공지·보도자료, 통계이야기, 데이터 시각화, 데이터통합채널
  • 부가 기능: 로그인/회원가입, 다국어(ENG), 외부 연계(KOSIS, R-ONE, KTDB, SEEREAL)

주요 개선 시그널 (Pain Points)

  1. UI/UX 한계: 비반응형 GNB 및 풀메뉴 패턴 사용, 웹 접근성(Accessibility) 속성 부족
  2. 시각화 부족: 시각화 기능이 특정 메뉴에 한정되어 있으며, 일반 통계 조회 화면 내 인터랙션 미흡
  3. 서비스 정적 구조: API 및 마이크로데이터 신청이 정적 프로세스 위주로 구성(셀프서비스 콘솔 부재)
  4. 외부 연계 미흡: 외부 통계포털 4종이 단순 링크(Outlink) 형태로만 노출 중

5. 한계 및 주의사항

⚠ 산정 방식 · 본 산정은 외부 공개 화면과 일반적 통계포털 기능을 기반으로 한 개략(Planning) FP입니다. 실제 RFP 단계에서는 상세 기능정의서 작성 후 DET/RET를 포함한 정식 IFPUG 산정법으로 재산정이 필요합니다.
  • 비기능 요소: 보안(21번) 및 성능(22번) 항목은 FP보다 인프라 설정 및 운영 솔루션 비용 비중이 크므로 별도 예산 수립을 권고합니다.
  • 연계 확장성: 외부 연계 포털(KOSIS 등)과의 API 데이터 연동 범위가 확대될 경우 외부인터페이스파일(EIF) 추가로 인해 전체 FP가 상승할 수 있습니다.
  • 일정 및 인력: 152 MM 기준 1년 6개월 ~ 2년의 사업 기간과 다전문 분야(백엔드·프런트·QA·디자인·기획·인프라) 인력이 필요합니다.
